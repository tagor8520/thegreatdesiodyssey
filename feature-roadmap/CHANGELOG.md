# Feature Changelog

All significant feature, architecture, research, budget, and roadmap changes are recorded here. Entries use local project dates (`Asia/Kolkata`) and canonical IDs from [`README.md`](./README.md).

This project does not yet publish semantic releases. Until it does, changes are grouped by date and implementation state. A source change is listed as **Added** only after its test/build gate passes; unfinished work stays under **In progress**.

## Unreleased

- `COL-06` — Every current static curated structural family now has tight tested camera compounds; moving landmark/skyline/railway validation remains before the matrix can call the feature complete.

### Added

- `LIF-01` / `LIF-03` — Replaced the tile-local bird and bee meshes with versioned `gdo:ambientLifeMotion:v1` owner-scoped sprite pools. Every agent is now a flat ten-triangle silhouette of five coplanar quads at local `z = 0`, billboarded in view space by the shared vertex program; the former 3D bodies (144 triangles) and their per-tile `birds:<key>`/`bees:<key>` `InstancedMesh` instances are gone, and ambience stays visual-only with no solid, camera, interaction, or clearance proxy.
- `LIF-03` — Moved all ambient motion into one shared vertex program driven by a single `vec2` clock uniform. Centre position, travel along an elongated path, bounded lateral weave, climb/hover, wing flap, appearance envelope, and camera-distance fade are evaluated per vertex from packed instance attributes, so a steady frame performs one uniform write, zero matrix updates, and zero steady-frame allocations; the CPU mirror exists only for tests and diagnostics.
- `LIF-01` — Replaced the perpetual closed orbits with longer deterministic non-looping routes. Each appearance cycle re-rolls heading jitter, travel length, lateral weave, climb, and hover from a splitmix32 channel hash, so an agent advances monotonically along one heading with bounded sideways sway and never retraces its own track. Measured over 80 record indices × 3 appearance cycles with 240 interior samples per window, every route stays elongated (minimum path length `.736`/`.791` and minimum end-to-end chord `.719` of declared travel for birds/bees), keeps its lateral span a bounded fraction of the along-heading span (`.166` birds, `.526` bees), and never reverses into its own track (worst per-segment agreement with the mean heading `.651` birds, `.045` bees); all 40 sampled cycles re-rolled a distinct heading/travel key.
- `LIF-01` — Agents now appear and disappear instead of existing forever. Every cycle declares a live fraction (birds `.60–.74`, bees `.52–.68`) of a `20–38 s` bird or `9–17 s` bee cycle, with smoothstep fade-in and fade-out and a deterministic dormant gap between windows; the stable owner ID, anchor, terrain-height offset, and family silhouette survive the gap so the same agent re-enters on its next window.
- `LIF-01` — Added flat generated bird and bee silhouettes with a distinct wing part that flaps around the body axis, a stable per-cycle phase, and a two-sided unlit sprite material. Flat sprites, part ids, wing motion, and path rolls are byte-stable across recompiles and remounts; reduced motion parks each agent at its anchor offset along the frozen heading with no clock term and no flap.
- `DET-05` — Added the versioned `gdo:streetFurniture:v1` grammar over `DET-02` for seven recognizable visual-only families: lamps, benches, bollards, bins, signs, bus shelters, and utility boxes. ### Lifecycle and budgets

- Ambient life is capped at `MAX_AMBIENT_LIFE` 30 records per source tile and four resident owner pools, and every pool is bounded per family at 30 live instances, 1,000 visible triangles, two added draws, 8 KiB of instance storage, one clock-uniform write, zero CPU matrix updates, and zero steady-frame allocations. Over-cap records are pruned deterministically instead of growing the pool, and the existing 30-visible-fauna low-profile research target still holds at 13–16 instances per family on the canonical fixtures.
- Ambient pools own their geometry and release the cloned per-family sprite geometry, material, and instance buffers on eviction and disposal, keep typed instance arrays for context restoration, and pre-validate every record of an owner before committing any pool state. A malformed, truncated, or non-finite stream throws with no owner left behind, empty streams delete the owner, and an evicted tile's ambience leaves no resident agent.

- Building detail adds no request, texture, material, collider, listener, timer, or per-box scene object. Four source-tile payloads may remain resident, but only the current focus tile exposes one merged detail draw and at most eight detailed buildings; focus changes toggle visibility without rebuilding geometry. Eviction disposes the tile geometry, and source arrays transfer through the existing post-road/context building phase.
- The dense fixture is the detail maximum at 2,956 road tests, eight selected buildings, 88 boxes, 1,056 triangles, and 88,704 typed bytes. The shared worker-output maxima become 17 draws, 111,502 triangles, 657,054 estimated typed GPU/instance bytes, and the unchanged 11,888 collision/support bytes/tile—below existing global ceilings.
- Water-domain compilation and transfer are bounded independently from rendered water: class/flow fields add no draw, material, texture, request, or steady-frame simulation. The low profile rejects any hydrology payload above 512 KiB, canonical fixtures peak at 77 bytes/tile, and empty domains retain only the required 16 bytes of offset arrays.
- Canonical fixture payloads remain test-only and are not imported by the playable coordinate bundle. The compact runtime snapshot/budget/debug modules are dynamically imported only after `F3`, the Debug button, or `?debug=1` requests them.
- Debug geometry refreshes at most every 250 ms, replaces and disposes one shared line buffer, is capped at 6,000 segments, and removes its scene object/material/listeners on mode disposal.
- Road-support records use a compact transferred stride-8 `Float32Array`; runtime support queries inspect only the local 8-unit spatial cell plus a bounded oversized-record list instead of scanning every road segment.
- Visual junction generation stops at 1,200 patches without discarding road ribbons or authoritative support records; patches remain in the existing road draw rather than adding per-junction objects or draw calls.
- Terrain geometry is tile-owned and disposed on eviction. The existing four-resident-tile/two-request streaming limits remain unchanged.
- Object recipes enforce explicit module and box budgets, and their collision, interaction, and camera outputs can only come from declared proxy fields—not decorative visual boxes or visual bounds.
- The procedural engine is the only normal material-library owner. Concurrent consumers share one allocation; the last reference cancels unfinished generation and disposes all five textures. Direct `GeoWorld` use acquires/releases a tested fallback owner.
- Coordinate debug diagnostics now report each generated texture's dimensions, format, colour space, mip-aware byte estimate, and checksum, and include shared material bytes in the live low-profile report.
- Plant archetype libraries are keyed by profile/environment/version, reference-counted, compile each requested family/variant once, enforce cache ceilings, and clear their CPU IR on final release. Placement creation does not populate the archetype cache.
- Plant geometry libraries share those skeleton owners, lazily compile each requested variant once, enforce profile-global archetype/byte caps plus an eight-library lifecycle cap, and release all typed-array references and their skeleton handle on final release. The direct exposed-face baseline for all twelve low variants is 107,904 bytes and 1,686 triangles.
- Plant LOD libraries compile each family/variant set once, own all three tier arrays through one reference-counted skeleton handle, enforce profile-global set/geometry/byte caps and an eight-library cap, and clear every tier on final release. The twelve low sets contain 36 geometries in 153,344 bytes; summed complexity falls from 1,248 near triangles to 856 mid and 292 far.
- The owner-aware selector is capped at 5,360 low entries, allocates state only when a placement is registered, accepts caller-owned result objects, removes owner state explicitly on eviction, and clears all entries on disposal. Stable source/owner IDs cannot be rebound silently.
- Plant compilation/upload is queued only after the tile's buildings/collision phase marks the world usable, so optional vegetation cannot delay roads-first readiness. The pool retains typed arrays for Three context restoration and explicitly disposes instance buffers, static tier geometries, material, selector state, and the reference-counted LOD library.

## Changelog rules

For every future change:

1. Add the canonical feature ID.
2. Use **In progress** until checks and required acceptance gates pass.
3. Record user-visible behavior, architecture/contracts, budget impact, fallback, and migrations—not every internal line edit.
4. Move a matrix item to **ADDED** or **PARTIAL** in the same change.
5. Record breaking seed/schema/save changes with old/new version and migration behavior.
6. Record rejected experiments when their measured result should prevent repetition.
7. Keep newest entries first; never rewrite old outcomes to imply unfinished work was complete.
